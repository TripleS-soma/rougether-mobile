# 스토어 리스팅 문구

App Store Connect / Google Play Console에 올리는 **텍스트 메타데이터의 단일 출처**입니다.
각 파일의 내용이 곧 콘솔 입력값입니다 — 주석이나 머리말을 넣지 마세요.

## 왜 저장소에 두는가

문구가 콘솔에만 있으면 **코드에서 기능을 지워도 리스팅이 그대로 남습니다.** 실제로 그랬습니다:

- 사진 인증 UI 제거 (#695, #712)
- 인앱 도움말에서도 제거 (#797) — 커밋 메시지가 "앱에 없는 기능이다"
- **스토어 설명에는 "사진 인증 루틴으로 진짜 했는지 확인하고"가 그대로 남음** (2026-08-14 발견)

App Store 심사 가이드 **2.3(정확한 메타데이터)** 위반이고, 리뷰 대상이 아니었기 때문에 아무도 못 봤습니다.
이제 여기 있으니 기능 제거 PR의 diff에 함께 걸립니다.

## 구조

```
store/ko-KR/
  app-store/
    name.txt              앱 이름            ≤ 30자
    subtitle.txt          부제               ≤ 30자
    promotional-text.txt  프로모션 텍스트     ≤ 170자
    keywords.txt          키워드             ≤ 100자 (쉼표 포함, 쉼표 뒤 공백 금지)
    description.txt       설명               ≤ 4000자
    release-notes.txt     새로운 기능         ≤ 4000자
  play/
    title.txt             제목               ≤ 30자
    short-description.txt 간단한 설명         ≤ 80자
    full-description.txt  자세한 설명         ≤ 4000자
```

`store/__tests__/metadata-limits.test.ts`가 글자 수 상한과 "앱에 없는 기능 홍보 금지"를
검사합니다. `npm test`에 포함되므로 CI가 자동으로 막습니다.

## 반영 절차 (수동)

자동 업로드는 없습니다 — 콘솔에 사람이 붙여넣습니다.

1. 여기서 문구를 고치고 PR → 머지
2. App Store Connect / Play Console에 붙여넣기
3. 아래 동기화 표의 상태·날짜 갱신

**App Store 주의**: 이름·부제·키워드·설명·스크린샷은 **버전에 묶입니다.** 심사 중인 버전이
있으면 수정할 수 없고, 심사에서 내리거나(순번 초기화) 다음 버전 제출 때 함께 올려야 합니다.
**프로모션 텍스트만 언제든 바꿀 수 있습니다** — 급한 공지는 이 칸을 쓰세요.

## 동기화 상태

`콘솔 = 여기`가 확인된 필드만 ✅입니다.

| 필드                         | 상태          | 비고                                                                |
| ---------------------------- | ------------- | ------------------------------------------------------------------- |
| app-store / name             | ✅ 2026-08-14 | 라이브 리스팅 조회로 확인                                           |
| app-store / subtitle         | ✅ 2026-08-14 | 라이브 리스팅 조회로 확인                                           |
| app-store / description      | ⚠️ 대조 필요  | 사진 인증 문구를 뺀 상태. 1.1.0 심사본에 저장된 실제 값과 대조할 것 |
| app-store / keywords         | ⬜ 미반영     | **콘솔 값을 여기로 복사해야 함** (외부 조회 불가)                   |
| app-store / promotional-text | ⬜ 미설정     | 콘솔에도 비어 있는 것으로 보임                                      |
| app-store / release-notes    | ⬜ 미설정     | 라이브 1.0에 "새로운 기능" 없음                                     |
| play / *                     | ⬜ 미출시     | Play 등록 전 (계정 재등록 대기)                                     |

## 알려진 ASO 과제

2026-08-14 감사에서 나온 것들. 심사 통과 후 다음 버전에 함께 반영합니다.

- **이름이 30자 중 3자만 사용** — `루게더`는 조어라 검색량이 없다. 이름 필드는 한국
  App Store에서 검색 순위 가중치가 가장 크다. `루게더 - 루틴 습관 트래커` 형태 검토.
- **부제 16/30자** — `루틴`·`습관`은 들어갔고 여유가 있다.
- **스크린샷 5장이 캡션 없는 원본 캡처** — 재화가 `9999+` 디버그 값이고, 루틴 이름이
  `루게더 개발`·`소마 정기 회의`이며, 테마도 현재(분홍)와 다른 초록 계열이다.
  (스크린샷은 이 폴더가 아니라 콘솔에서 관리한다 — 파일이 커서 저장소에 두지 않음)

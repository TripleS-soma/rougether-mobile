# UI 아이콘 에셋

앱에 **번들되는** UI 아이콘(하단 탭·상단바 버튼)을 여기에 둡니다. 코드에서
`require('@/assets/icons/...')`로 정적 참조하므로 파일은 반드시 이 경로에 있어야 합니다.

> 가구·캐릭터·벽지 이미지는 여기 두지 않습니다. 그것들은 원격 리소스(CDN)에서
> `assetSource(key)`(`src/resources/asset.ts`)로 불러옵니다 — `*_key` + CDN base 규약.

## 폴더

| 폴더       | 용도                                                                                |
| ---------- | ----------------------------------------------------------------------------------- |
| `nav/`     | 하단 네비게이션 탭 아이콘 (나의 방 / 집 / 설정)                                     |
| `actions/` | 상단바·헤더 액션 아이콘 (뒤로 / 편집 / 가챠 / 추가 / 검색 / 구성원 / 닫기 / 더보기) |

## 파일 스펙

- **PNG, 배경 투명**, 정사각형
- 해상도: 단일 파일이면 **최소 96×96px**(클수록 좋음), 또는 `name.png` / `name@2x.png` / `name@3x.png` 세트(Metro가 자동 선택)
- 색상 방식 두 가지:
  - **단색(모노)**: 한 장만 주면 코드에서 활성=primary색 / 비활성=회색으로 **틴트**합니다. (권장 — 테마와 자동 일치)
  - **풀컬러**: 그대로 표시. 활성/비활성을 다르게 하려면 `-active` 변형을 같이 주세요.

## 파일명 규칙 (이 이름으로 주시면 바로 연결됩니다)

### `nav/` — 하단 탭

| 탭      | 파일               |
| ------- | ------------------ |
| 나의 방 | `nav/my-room.png`  |
| 집      | `nav/house.png`    |
| 설정    | `nav/settings.png` |

활성/비활성을 따로 줄 경우: `my-room.png`(비활성) + `my-room-active.png`(활성) 형태.

### `actions/` — 상단바/헤더 (바꿀 것만 주셔도 됩니다)

| 의미            | 파일                  | 현재 이모지 |
| --------------- | --------------------- | ----------- |
| 뒤로 가기       | `actions/back.png`    | ‹           |
| 방 편집         | `actions/edit.png`    | ✎           |
| 가챠(뽑기) 상점 | `actions/gacha.png`   | 🎁          |
| 루틴/할 일 추가 | `actions/add.png`     | ＋          |
| 집 탐색(검색)   | `actions/search.png`  | 🔍          |
| 구성원          | `actions/members.png` | 👥          |
| 닫기            | `actions/close.png`   | ✕           |
| 더보기(케밥)    | `actions/kebab.png`   | ⋮           |

## 연결 방법 (개발)

파일을 넣은 뒤, 아이콘 require를 한곳에서 관리하기 위해 `src/resources/icons.ts`(추후 추가)에
매핑하고, `BottomNav`/헤더에서 `<Image source={...} />`로 사용합니다. 단색 아이콘은
`tintColor`로 활성/비활성 색을 줍니다.

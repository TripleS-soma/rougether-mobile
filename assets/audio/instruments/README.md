# 밴드 악기 터치 효과음

Rougether 밴드 가구용으로 2026-09-22 직접 합성한 원본 효과음 4종입니다. 외부 녹음·음악 샘플을 사용하지 않았습니다. 기타·베이스는 현 감쇠 합성, 드럼은 사인파·잡음 감쇠, 키보드는 배음 합성으로 만들었습니다.

서버 에셋 원본은 `items/cozy-band-room/audio/{악기}-tap-v1.wav`에 있습니다. 앱은 최초 터치 지연과 네트워크 실패를 줄이기 위해 동일한 WAV를 번들에 포함합니다. 44.1kHz / mono / 16-bit PCM, 0.78~1.50초, 피크 -8.4dBFS이며 재생 볼륨은 55%입니다.

이미지 asset key와의 연결은 `src/resources/instrument-sounds.ts`가 담당합니다. 카탈로그 item ID·사용자 보유 ID에 의존하지 않습니다.

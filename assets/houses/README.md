# 공동집 리디자인 에셋

`shared-v1/`은 AI로 제작한 공동집 배경 6종이다. 가구와 캐릭터를 굽지 않은 2층 개방형 그림이며, 원본 1024×1536을 768×1152 WebP로 변환했다. 테마별 발 위치와 하늘색은 `src/resources/house-diorama.ts`에서 함께 관리한다. 좌표는 원본 크기를 기준으로 정규화한다.

기존 커버 4종의 저장 키는 유지하고 앱에서 새 그림으로 해석한다. 신규 커버는 `forest-canopy`, `evening-brick`이며, 서버 게시 목록에 키를 추가해야 선택할 수 있다. 원격 PNG는 구버전 앱의 4개 투명 창문 규격을 유지한다. 기존 CDN 파일은 덮어쓰지 않는다.

집 화면과 탐색 미리보기는 같은 그림을 사용한다. 실제 배치된 가구 중 최대 2개와 캐릭터를 별도의 contain 영역에 렌더한다. 개인 방 방문에서는 기존 전체 방 렌더러를 사용한다. 가구가 없거나 카탈로그에서 찾을 수 없으면 장식을 만들어 넣지 않는다.

원본과 생성 프롬프트, 업로드 해시, 실제 Expo 웹 화면 검증 기록은 작업 워크스페이스의 `output/imagegen/house-renewal-2026-11-04`에 보관했다. 앱에 번들되는 파일은 이 폴더의 WebP 6개뿐이다. `EXPO_PUBLIC_HOUSE_DIORAMA=0`으로 기존 렌더링을 선택할 수 있다.

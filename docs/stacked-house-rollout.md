# 세로형 집 프레임 점진 적용 (#1077)

## 적용 범위

운영 데이터와 기존 앱의 `coverImageKey`는 바꾸지 않고, 지원 프론트가 화면을 그릴 때만 새 프레임으로 해석한다. 새 30개 파일을 공개 커버 목록으로 만들지 않는다.

| 상태                                                 | 화면                                       |
| ---------------------------------------------------- | ------------------------------------------ |
| 기본값, `EXPO_PUBLIC_STACKED_HOUSES` 미설정 또는 `1` | 기존 구름·산호·버섯 커버만 세로형으로 표시 |
| `EXPO_PUBLIC_STACKED_HOUSES=0`                       | 기존 프레임·4칸 및 초과 방 그리드          |
| 미지원 커버, 6인 초과, 비정상 정원                   | 기존 표시 유지                             |
| 세로형 이미지 로딩 실패                              | 이미지와 방 영역을 함께 기존 표시로 복귀   |

이 값은 **번들 생성 시 고정되는 Expo 환경 변수**다. 원격 실시간 스위치가 아니므로, 운영 전환·복구에는 해당 값으로 만든 새 번들 배포가 필요하다. #1114의 1.4.2 / 빌드 113 통합에서 기본 ON으로 바꾼다. 최초 #1077 PR은 기본 OFF였으며 네이티브 설정을 바꾸지 않았다.

공개 선택지는 서버 `GET /houses/cover-images`만 사용한다. 커버 선택·생성·수정 요청에는 항상 원래 키를 전달한다. 산호 조개 프레임은 기존 `coral-aquarium` 키 및 배경에 명시적으로 연결한다. 밤의 천문대 등 다른 커버는 그대로다.

나머지 7개 테마는 Dev 갤러리에서만 확인한다. 공개하려면 구버전 읽기 호환성과 서버 승인 카탈로그 계약을 별도로 확정해야 한다.

## 렌더 계약

정원 기준으로 1–2인은 2칸, 3–4인은 4칸, 5–6인은 6칸을 사용한다. 현재 멤버가 줄어도 건물 층수가 줄지 않는다. 정원보다 많은 방 데이터가 오면 방 수까지 고려하며, 6개 초과는 기존 그리드로 보존한다. **#1108 통합에서 신규 집 생성·정원 수정 선택지를 2–6명으로 확대한다. 기본값은 4명이고 기존 집은 자동 변경하지 않는다.**

| 변형 | 캔버스      | 방        |
| ---- | ----------- | --------- |
| 2인  | 1024 × 872  | 2열 × 1층 |
| 4인  | 1024 × 1224 | 2열 × 2층 |
| 6인  | 1024 × 1576 | 2열 × 3층 |

각 방은 320 × 320, x=165/536, y=358+352×행이다. 프레임 뒤에 `Room`을 합성하며 벽지·바닥·가구·캐릭터는 독립 레이어다. 어댑터의 아래층 우선 배치와 기존 좌석 인덱스를 보존하므로 자리 저장 마이그레이션은 없다. 방 내부 FREE_V1 정규화 좌표도 변경하지 않는다.

`src/resources/house-frame.ts`가 이미지와 영역의 공통 출처다. 상세, 탐색 카드·미리보기, 생성 미리보기, 생성/수정 커버 선택, 프리페치가 같은 resolver를 쓴다. 확대 카메라는 프레임의 실제 크기를 측정하며 정원·화면 크기 변경 또는 폴백 시 초기화한다. 길어진 탐색 미리보기는 스크롤되어 닫기·참여 버튼에 접근할 수 있다.

배포된 [에셋 manifest](https://d1eazfl0tw7r0v.cloudfront.net/house/releases/stacked-v1-20260905/manifest.json)와 로컬 resolver의 이미지 키·비율·방 좌표 30개가 일치하는 것을 별도로 대조했다.

## 로컬 확인

```bash
npm ci
EXPO_PUBLIC_STACKED_HOUSES=1 npx expo start --web --port 8095 --localhost
# http://localhost:8095/dev?entry=StackedHouseFrames
```

갤러리 버튼으로 10개 테마, 2/3/4/6인, 기존형 복귀, 미리보기/실제 집 화면을 전환한다. 검증용 구성원 및 실제 CDN 방 아트를 사용하며 API 쓰기는 없다. `previewTheme`는 `__DEV__`에서만 유효하고 `/dev`는 프로덕션에서 홈으로 이동한다.

```bash
npm run typecheck
npm run lint
npm run format:check
npm test -- --watchman=false --runInBand
git diff --check
```

2026-09-05 기준 전체 164개 suite / 1,278개 테스트 통과. 전체 실행 후 남은 비동기 핸들로 Jest가 종료되지 않아 종료했으며, 최종 전체 재검증은 `--forceExit --silent`로 통과했다. 신규 테스트 4개 suite / 16개는 `--detectOpenHandles`로 정상 종료했다. lint 오류는 없고 작업 범위 밖 `app-shell.tsx`의 기존 경고 1개가 남는다.

로컬 Chromium에서 10개 테마 × 2/4/6인(30개)의 CDN 프레임 디코딩과 방의 정사각형 비율을 확인했다. 실제 집 화면에서 위층 6번·아래층 1번 방 방문이 올바른 구성원으로 연결됐다. 1024px 폭에서도 6개 방이 각각 290.625px 정사각형을 유지하고 스크롤 후 아래층 방문이 동작했다. 브라우저에만 새 프레임 요청 실패를 주입했을 때 기존 567/508 비율로 복귀했다.

iOS/Android 기기의 실제 핀치·롱프레스 및 OTA 수신은 이 로컬 웹 검증에 포함하지 않는다. 공개 전 실기기 검증이 필요하다.

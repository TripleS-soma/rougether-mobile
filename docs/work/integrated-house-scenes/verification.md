## 화면 비율에 따른 전체 집 보호 후속 수정

폭만 맞추면 짧은 화면과 태블릿에서 기단이 내비게이션 뒤로 내려갈 수 있어, 집 보호영역을 실제 헤더·내비게이션 사이에 맞추도록 변경했습니다. 집 원본 12장과 48개 방 rect는 그대로입니다. 부족한 주변은 같은 테마의 환경 전용 번들 4장과 보호영역 밖 SVG alpha feather로 연결합니다. 모든 집 그림과 방은 같은 균일 축척을 사용합니다.

- 320×568, 390×844, 393×852, 430×932, 768×1024에서 12개 장면의 보호영역이 가로·세로 안전영역 안에 있고 방이 같은 축척으로 정렬되는지 검사합니다. 넓은 배경 원본은 집을 불필요하게 축소하지 않고 주변을 자르는 별도 회귀 사례를 포함합니다.
- 실제 HouseScreen의 12개 장면에 viewport·헤더 측정을 적용하고 좌석 방문, 스크롤 0, 방 정합성을 검사합니다. 전체 화면 fixture는 SafeAreaInsetsContext와 실제 BottomNav를 포함합니다.
- 테마·정원·헤더 높이·회전 시 카메라 리셋과 pager lock 해제, 진행 중 드래그 취소를 확인합니다. 당겨서 새로고침은 기본 위치에서 유지하고 자리 이동 중에는 잠깁니다.
- scene 또는 backdrop 로딩 실패 시 그림·방 좌표가 함께 기존 프레임으로 전환됩니다. Expo probe가 성공해도 실제 SVG가 15초 안에 onLoad를 보내지 않으면 동일하게 복귀합니다. 성공과 언마운트 시 timer 정리도 검사합니다.
- SVG mask의 네이티브 gradient는 보호영역 안에서 alpha 255를 유지하고 바깥만 최대 화면 24px로 페이드하는지 확인합니다. 웹 접근성은 RN View 한 곳에만 노출하고 maskType은 네이티브·웹이 공통 지원하는 style 속성을 사용합니다.
- 이름표는 통합 방 위쪽에 놓고 `bottom: auto`를 명시하여 웹에서 아래 좌표가 남지 않게 합니다. 64px 미만 방은 이름표만 숨기고 접근성 이름·방문·자리 이동은 유지합니다. 320×568과 393×852 night 6인에서 고양이 6마리와 이름표/접근성 동작을 직접 확인했습니다.
- 최종 production 호환 소스: 256 suites, 2,084 tests 통과.
- 최종 dev 소스: 266 suites, 2,170 tests 통과.
- 양쪽 typecheck·lint·format·diff 검사 통과. 기존 `app-shell.tsx` hook 의존성 경고 1개와 Jest 종료 옵션은 위 기록과 같습니다.
- 최종 iOS fingerprint: `8441e2f0e567fbd486e3a699fd20ec36c4a82ca2`로 기존 설치본과 동일합니다. 새 네이티브 모듈이나 앱 설정 변경은 없습니다.

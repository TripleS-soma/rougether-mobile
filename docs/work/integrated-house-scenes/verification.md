## 실제 RN Web 확인

고정 fixture와 공개 에셋으로 확인했으며 개인 회원 API 데이터는 사용하지 않았습니다.

- 390×844에서 12개 조합을 모두 열었습니다. 방 48개가 화면 영역 안에 있고 별도 배경이 중복 렌더되지 않았습니다.
- 각 장면의 그림, 벽, 바닥, 가구, 캐릭터를 포함한 이미지 252개가 로드되었습니다.
- 2인 좌석 순서는 `1, 2`, 4인은 위부터 `3, 4 / 1, 2`, 6인은 `5, 6 / 3, 4 / 1, 2`였습니다.
- 실제 집 화면에서 2번 멤버를 눌러 해당 membershipId의 방문 콜백을 확인했습니다.
- 별도 검토자가 mushroom/cloud 6인(390×844), coral 4인(375×667), night 6인(320×568)의 자연스러운 접합과 방 경계·순서를 확인했습니다.
- 브라우저 도구가 반환한 inline 캡처로 확인했습니다. 별도의 스크린샷 파일은 저장하지 않았습니다.

개발 갤러리: `/dev?entry=IntegratedHouseScenes`.

전체 화면 예: `/dev?entry=IntegratedHouseViewport&viewport=1&theme=cloud-balloon&capacity=6`.

갤러리에서 실제 집/탐색 미리보기, 빈자리, 레거시 프레임으로 전환할 수 있습니다. 다크 모드의 색 처리와 핀치 줌·롱프레스 자리 교환은 네이티브 실기기에서 추가 확인이 필요합니다. 웹 확인을 실기기 확인으로 간주하지 않습니다.

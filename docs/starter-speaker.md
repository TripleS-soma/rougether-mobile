# 첫 가구 스피커

신규 가입 시 포근한 스피커를 한 개 지급하고 빈 방에 배치한다. 모바일은 기존 아이템·인벤토리·방 API 응답을 그대로 사용하며 `items/starter/furniture/starter-speaker-v1.webp` 키로 인터랙션을 판별한다. 기존 회원에게 소급 지급하지 않는다.

내 방에서 스피커를 누르면 모닥불·빗소리·숲·피아노를 선택하고 재생/정지와 볼륨 조절을 할 수 있다. 재생 여부에 맞춰 스피커가 움직이며 OS 동작 줄이기를 따른다. 방문·편집용 방은 소리를 재생하지 않는다. 소리 선택과 볼륨만 기기에 저장하고 재시작 시 자동 재생하지 않는다. 방 이탈·앱 백그라운드·스피커 배치 해제·언마운트에서 플레이어를 해제한다.

반복 시 웹은 디코딩한 PCM의 끝/시작 2초를 교차 혼합한 AudioBuffer를 반복한다. 네이티브는 준비한 두 expo-audio 플레이어를 종료 2초 전에 교차 재생하여 EOF 뒤 seek를 기다리는 공백을 피한다. 플레이어 교체와 정지는 비동기 재생 요청을 무효화한다. 로딩이 15초 안에 끝나지 않으면 취소 후 재시도를 안내한다.

음원 원작·CC0 출처는 `assets/audio/speaker/LICENSES.md`, 이미지 제작 내역은 `assets/images/furniture/README.md`에 기록했다. 음원은 앱에 포함한다.

## 검증

- 개발 미리보기: `/dev?entry=SpeakerPreview&viewport=1` (API 쓰기 없음)
- 재생 후 음원 선택, 0~100% 볼륨, 정지, 다시 시작, 반복 경계를 확인한다.
- 앱/브라우저를 백그라운드로 보냈다 돌아와도 자동 재생하지 않아야 한다.
- 신규 가입 통합 테스트는 한 번 지급·실제 배치·중복 호출·배치 제거 후 재호출·가입 실패 전체 롤백을 검증한다.

## 릴리스 순서

1. 번들 이미지와 동일한 파일을 위 CDN 키에 업로드하고 응답을 확인한다.
2. 오디오 모듈을 포함하는 새 모바일 빌드를 검증한다. 기존 설치본에 JS OTA만 보내면 안 된다. 마이크·백그라운드 오디오 권한은 요청하지 않는다.
3. 서버 V76 마이그레이션과 가입 시 지급 로직을 함께 배포한다. 마이그레이션 번호 충돌 여부를 병합 시 확인한다.
4. 신규 계정에서 인벤토리·방 배치·스피커 재생을 확인하고 스토어 설명을 반영한다.

로컬 구현·테스트 완료와 CDN 업로드·서버 배포·스토어 반영은 별도 상태로 관리한다.

# 첫 가구 스피커

신규 가입 시에는 첫 뽑기 자격만 부여한다. 온보딩의 첫 가구 뽑기에서 무료로 포근한 스피커 한 개를 받고, 결과 화면에서 방 꾸미기로 이동해 직접 배치한다. 일반 유료 뽑기와 별도 API를 사용하며 `items/starter/furniture/starter-speaker-v1.webp` 키로 인터랙션을 판별한다. 기존 회원에게 소급 지급하지 않는다.

내 방에서 스피커를 한 번 누르면 재생·정지를 전환한다. 길게 누르면 모닥불·빗소리·숲·피아노 선택과 볼륨 설정을 연다. 재생 여부에 맞춰 스피커가 움직이며 OS 동작 줄이기를 따른다. 방문·편집용 방은 소리를 재생하지 않는다. 소리 선택과 볼륨만 기기에 저장하고 재시작 시 자동 재생하지 않는다. 방 이동·폰 잠금·앱 백그라운드에서도 재생을 유지한다. 스피커 배치 해제·로그아웃·앱 셸 언마운트 시 플레이어를 해제한다. 아이폰 잠금화면과 제어센터에서 재생·일시정지를 제어한다. 전화·헤드폰 연결 해제 시 일시정지하며 자동 재개하지 않는다.

반복 경계의 끝/시작 2초를 미리 교차 혼합한 44.1kHz 스테레오 PCM WAV를 번들에 포함한다(4종 약 36MiB). `python3 scripts/prepare-speaker-loops.py`로 기존 MP3에서 재생성한다. iOS는 로컬 Expo 모듈의 AVAudioPlayer 무한 반복과 MPRemoteCommandCenter, Android는 expo-audio/ExoPlayer 네이티브 반복·잠금화면 미디어 세션, 웹은 AudioBuffer 반복을 사용한다. 반복과 iOS 잠금화면 제어에는 JS 타이머를 사용하지 않는다. 플레이어 교체와 정지는 비동기 재생 요청을 무효화한다. 로딩이 15초 안에 끝나지 않으면 취소 후 재시도를 안내한다.

음원 원작·CC0 출처는 `assets/audio/speaker/LICENSES.md`, 이미지 제작 내역은 `assets/images/furniture/README.md`에 기록했다. 음원은 앱에 포함한다.

## 검증

- 온보딩 미리보기: `/dev?entry=StarterSpeakerPreview&viewport=1` (무료 뽑기 → 수동 배치, API 쓰기 없음)
- 개발 미리보기: `/dev?entry=SpeakerPreview&viewport=1` (API 쓰기 없음)
- 재생 후 음원 선택, 0~100% 볼륨, 정지, 다시 시작, 반복 경계를 확인한다.
- 네이티브 앱에서 화면 이동 → 폰 잠금 → 음원 길이 이상 재생 → 잠금화면 일시정지·재생 → 앱 복귀 시 스피커 애니메이션 동기화를 검증한다. 웹 브라우저의 잠금 중 재생은 OS 정책에 따라 제한될 수 있다.
- 서버 통합 테스트는 가입 시 미지급·미배치, 무료 확정 지급, 동시 요청, 중복 수령 차단, 기존 완료 회원 제외, 재실행 차단, 트랜잭션 롤백과 인증을 검증한다.
- 모바일 테스트는 전용 API 호출, 응답 유실 후 보상 조회 복구, 중복 탭 방지, 무료 1회 버튼과 수동 배치 이동을 검증한다.

## 릴리스 순서

1. 번들 이미지와 동일한 파일을 위 CDN 키에 업로드하고 응답을 확인한다.
2. 오디오 모듈을 포함하는 새 모바일 빌드를 검증한다. 기존 설치본에 JS OTA만 보내면 안 된다. 마이크·녹음 권한은 요청하지 않는다. iOS audio 백그라운드 모드와 Android 미디어 재생 foreground service를 사용한다.
3. 서버 V76(스피커 카탈로그), V77(첫 뽑기 자격)과 전용 API를 모바일 공개 전에 배포한다. 마이그레이션 번호 충돌 여부를 병합 시 확인한다.
4. 신규 계정의 무료 첫 뽑기 → 인벤토리 → 직접 배치 → 재생을 확인한다. 기존 완료 계정의 다시 보기에서는 무료 지급이 없어야 한다. 스토어 설명을 반영한다.

로컬 구현·테스트 완료와 CDN 업로드·서버 배포·스토어 반영은 별도 상태로 관리한다.

## 온보딩 뽑기 계약

모든 요청은 로그인 토큰의 회원을 대상으로 한다. 요청 본문으로 회원·가구·뽑기 횟수를 지정하지 않는다.

| API                                          | 동작                                                                        |
| -------------------------------------------- | --------------------------------------------------------------------------- |
| `GET /api/v1/onboarding/starter-gacha`       | `state`와 `reward` 조회. 수령 후 응답을 잃었을 때도 동일한 결과를 복구한다. |
| `POST /api/v1/onboarding/starter-gacha/draw` | 무료 스피커 1개 확정 지급. 일반 뽑기와 같은 `results`·`wallets` 응답.       |
| `POST /api/v1/onboarding/tutorial/complete`  | 미사용 자격을 닫는다. 반복 호출은 204, 수령 이력은 유지한다.                |

`users.onboarding_starter_draw_state`는 `PENDING → CLAIMED` 또는 `PENDING → CLOSED`로만 바뀐다. 재실행으로 역전되지 않는다. 목표·캐릭터 선택의 `onboarding.completed`는 뽑기보다 먼저 완료되므로 별도 상태를 사용한다. V77 적용 당시 목표와 대표 캐릭터 선택을 모두 마친 회원은 CLOSED로 유지하며, 미완료 정상 회원과 이후 가입자는 PENDING이다. 봇·탈퇴 회원에게는 부여하지 않는다.

회원 행 잠금 안에서 인벤토리 저장과 수령 상태를 함께 커밋한다. 이미 수령한 요청은 `409 ONBOARDING_STARTER_DRAW_ALREADY_CLAIMED`, 자격이 없으면 `403 ONBOARDING_STARTER_DRAW_NOT_ELIGIBLE`, 스피커 카탈로그 사용 불가 시 `503 ONBOARDING_STARTER_DRAW_UNAVAILABLE`이다. 실패를 일반 유료 뽑기로 재시도하지 않는다. 지갑·방 배치는 변경하지 않는다.

# 채팅 이모티콘의 웹 미리보기와 iOS 이미지 지원을 나눠 확인하기

- 날짜: 2026-11-15 / 집 채팅 / 이슈 #1779, PR #1780
- 키워드: 이미지 디코더, WebP, Expo Image, OTA 호환성

## 배경

습관 형성을 돕는 소셜 루틴 앱의 집 채팅에 고양이 이모티콘 8종을 추가했다. 선택 패널, 반투명 미리보기와 받은 메시지에 같은 투명 WebP 에셋을 사용한다. 이모티콘과 입력한 글은 같은 메시지로 보낸다.

## 문제 (증상)

브라우저에서는 그림이 표시됐지만, 그 결과만으로 iOS 설치본에서 사용하는 이미지 디코더의 지원 여부까지 확인할 수는 없었다. 앱 배포 전 이미지 렌더러와 파일 형식을 추가로 대조했다. 이 기록의 확인 범위는 코드, 공식 지원 문서와 자동 테스트이며 실기기에서의 표시 확인은 별도 항목이다.

## 원인 분석 (가설 → 검증 과정)

초기 구현의 세 컴포넌트는 React Native 기본 `Image`를 사용했다. 설치된 React Native 소스의 `Libraries/Image/ImageProps.js`는 WebP 지원을 Android 한정으로 설명한다. 반면 [Expo SDK 55 Image 문서](https://docs.expo.dev/versions/v55.0.0/sdk/image/)는 WebP를 iOS, Android와 웹에서 지원한다고 명시한다. 기존 채팅 사진 컴포넌트도 이미 `expo-image`를 사용하고 있었다.

## 해결

선택 패널, 선택 미리보기와 받은 메시지의 이모티콘을 기존 `expo-image`의 `Image`로 통일하고 `contentFit="contain"`을 적용했다. 새 네이티브 의존성이나 앱 설정을 추가하지 않았으며 승인된 그림과 배치도 유지했다.

## 결과 (수치)

이미지 표시 코드 변경은 세 파일이다. 배포 직전 타입, 린트와 포맷 검사가 통과했고 전체 475개 테스트 모음에서 4,044개가 통과했다. 기존 todo는 4개다. 스토어 설치본에는 기존 런타임을 기준으로 한 별도 브랜치를 사용하고, 발행 워크플로에서 목표 런타임 일치를 검사한다. 테스트 통과와 OTA 발행은 실기기에서 그림이 표시됐다는 증거와 구분해 기록한다.

## 배운 점 / 재발 방지

투명도와 브라우저 렌더링 확인에 더해 실제 앱의 이미지 컴포넌트가 각 플랫폼에서 파일 형식을 지원하는지 확인한다. 이미 포함된 이미지 모듈을 재사용해 불필요한 네이티브 재빌드를 피하고, 설치본 도달 여부는 OTA 채널과 런타임을 함께 대조한다.

# 고양이 시그니처 포즈 리뉴얼

관련 이슈: #1250. 최초 사용자 캡처의 큰 머리, 짧고 둥근 몸, 회색 털과 회갈색 선을 기준으로 8종 모션을 다시 제작했다. 누워서 고개를 흔드는 기본 대기를 유지한다.

## 화면별 동작

내 방은 고개 흔들기 → 깜빡임 → 윙크 → 두리번 → 인사 → 기지개 → 잠들기 → 세수를 터치마다 순환한다. 모든 포즈가 반복 재생되며 8번 터치하면 기본 눕기로 돌아온다. 친구 방과 친구 헤더는 새 기본 눕기의 첫 프레임인 `cat-approved-still.webp`를 사용하고 포즈 버튼을 표시하지 않는다. 캐릭터 선택·프로필·뽑기는 기본 눕기 모션을 사용한다.

`src/resources/character-art.ts`가 8종과 친구 방 정지 원화를 관리한다. `CharacterAvatar`는 옛 서버 고양이 포즈보다 이 번들 목록을 우선한다. 다른 동물, 보유·선택 ID, 서버 카탈로그와 S3는 변경하지 않는다. 포즈 사이를 연결하는 전환 동작은 포함하지 않는다.

## 공통 원화와 제작 방식

최초 캡처에서 고양이를 추출한 `original-reference.png`로 공통 원화 `model-sheet.png`를 만들고, 내장 imagegen으로 8종 모두 전체 캐릭터의 연속 그림을 생성했다. 이전 갈색 시안은 참조하지 않았다. 원본 시트와 실제 프롬프트는 [`cat-consistent/prompts.md`](../assets/characters/cat-consistent/prompts.md)에 있다.

`build-consistent-cat.py`는 실제 캐릭터 윤곽별로 그림을 분리해 배경을 제거한다. 각 동작 첫 그림의 상단 35%에서 머리·귀의 연결 윤곽 폭을 320px로 맞추고 그 배율을 해당 동작 전체에 동일하게 적용한다. 전체 포즈 높이로 크기를 맞춰 기지개의 머리가 작아지던 문제를 피한다. 이는 해부학적 머리 크기의 정밀 측정이나 동일성 점수가 아니다.

모든 그림에 공통 원화의 128색 팔레트를 적용하고, 앞발 기준점으로 그림 전체 위치를 정렬한다. 인사는 화면 왼쪽 지지발, 세수는 오른쪽 지지발, 나머지는 앞발 발끝의 바깥쪽 범위 중심을 기준으로 한다. 기지개의 뒷발은 제외한다. 팔레트 적용 후 재측정하여 정수 픽셀 이동을 보정한다. 디코딩된 영상에서 이 기준점의 좌우·바닥 범위가 각각 2px 이하인지 검사한다. 고개 회전에 따른 얼굴 이동과 개별 윤곽 변화까지 고정한다는 의미는 아니다.

분리한 팔 회전, Blender, 부분 메시 변형, 광학 보간은 8종 모두 사용하지 않는다. 인사에서 반대 발을 드는 그림, 세수의 과도한 혀 그림, 두리번의 눈이 이상한 중간 그림을 제외했다. 실제 선택 순서는 각 `*-verification.json`의 `source_cell_indices`에 기록한다.

## 재생 사양

모두 512×512 투명 무손실 WebP, 무한 반복이다. 끝에 첫 그림을 재사용한다. 동일한 연속 그림은 인코더가 한 프레임으로 합칠 수 있다.

| 동작      | 인코딩 프레임 | 주기   |
| --------- | ------------- | ------ |
| 기본 눕기 | 16            | 3.2초  |
| 깜빡임    | 16            | 2.56초 |
| 윙크      | 16            | 2.56초 |
| 두리번    | 15            | 2.56초 |
| 인사      | 18            | 2.88초 |
| 기지개    | 16            | 2.56초 |
| 잠들기    | 16            | 4.8초  |
| 세수      | 17            | 2.72초 |

생성 그림 사이에 눈 간격·귀·외곽선의 작은 변화는 남아 있다. 약 3~6fps의 연속 그림이며 픽셀 수준의 동일성이나 완전한 자연스러움을 보장하지 않는다. 기지개는 짧은 몸과 큰 머리를 유지하며 뒷발 하나가 드러나는 동작이다.

## 재생성 및 검증

Python 3, Pillow, numpy, OpenCV 환경에서 아래 명령만 실행한다.

```sh
python3 scripts/build-cat-motion-set.py
npx prettier --write assets/characters/cat-consistent/*.json assets/characters/cat-approved/motion-set-verification.json
python3 scripts/build-cat-motion-set.py --verify-only
```

`build-cat-motion-set.py`는 8종을 새 빌더로 조립하고 친구 방 정지 파일도 함께 갱신한다. `cat-approved`, `cat-drawn`의 옛 시트·리그·인코딩 기록과 이전 빌더는 과거 시안이며 현재 제작 경로가 아니다. 과거 빌더를 연속 실행하지 않는다.

현재 검증 자료는 `cat-consistent/*-verification.json`이다. 시트·결과물 해시, 선택 순서, 배율, 앞발 좌표, 실제 프레임 수·주기·위치 범위를 기록한다. `motion-set-verification.json`은 실제 번들의 움직임 존재, 시작·끝 일치, 잘림 없음, 최대 정지 시간과 친구 정지 파일 일치를 검사한다. 기존 `cat-approved/motion-set-verification.json`도 같은 최신 보고서로 갱신한다.

컴포넌트 테스트는 8종 순환·기본 복귀·친구 정지·버튼 부재를, 바이너리 테스트는 WebP 다중 프레임과 무한 반복을 확인한다. 개발 갤러리 `Room · 승인된 고양이`, `Room · 친구 고양이 (정지)`에서 직접 확인할 수 있다. 웹 검증과 iOS·Android 설치본 검증은 별개이며 업데이트 배포 전이다.

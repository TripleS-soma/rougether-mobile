# 캐릭터 스타일 가이드

2026-11-09 작성. 캐릭터가 "AI 같다"는 피드백(고양이 누운 포즈는 괜찮고, 2·3번 포즈와 다른 캐릭터는 어색하며, 움짤이 떠다닌다)에서 출발했다. **고양이 1번(누운 포즈, `assets/images/characters/cat-1.webp`)을 세트 전체의 기준**으로 삼는다.

이 문서는 세 부분이다. 지금 무엇이 어긋나 있는지(실측), 다시 만들 때 지킬 규격, 그리고 사람이 다듬는 단계와 합격 기준.

## 1. 지금 상태 — 왜 AI처럼 보이나

`python3 scripts/character-art-audit.py`로 번들 32장(8종 × 포즈 4)을 잰 결과다(332×285 캔버스 기준).

| 항목           | 실측                                                                                | 문제                                                            |
| -------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| 선 굵기        | 고양이·곰·말·수달·양 2px, **강아지·호랑이·판다 4px**, 일부 3px                      | 한 세트 안에 두 가지 굵기 — 한 사람이 그린 세트로 안 읽힌다     |
| 외곽선 색      | 판다 `#433826` ~ 강아지 `#896652` (밝기 차이 54)                                    | 종마다 선의 진하기가 다르다                                     |
| 해상도         | **곰만 166×143**(나머지 332×285)                                                    | 곰만 흐리게 보일 수 있다                                        |
| 볼터치         | `#ddc1b6` ~ `#f4c099`                                                               | 색도 종마다 다르지만 **위치는 전부 같다** — 도장 찍은 느낌      |
| 포즈 구성      | 8종 모두 같은 4포즈(누움·앉음·손 흔들며 윙크·서기)                                  | 종의 성격이 안 보인다. 3번의 반짝이·윙크·혀는 8종에 그대로 반복 |
| 포즈 간 일관성 | 고양이 2·3번은 1번과 머리·몸 비율, 눈 간격이 미묘하게 다름                          | 같은 고양이가 아니라 비슷한 고양이 여럿처럼 보인다              |
| 해부           | 손 흔드는 앞발의 발바닥이 정면으로 펴짐, 서기(4번)의 다리 길이·관절이 종마다 제각각 | AI 생성 그림에서 가장 흔한 어색함                               |
| 움직임         | 서버 포즈(움직이는 webp)가 몸 전체를 계속 출렁임                                    | "떠다니는" 느낌 — 무게가 없다                                   |

> 선 굵기 측정은 휴리스틱이다(가로 스캔의 어두운 픽셀 연속 길이 중앙값). 판다처럼 검은 털이 큰 캐릭터는 털 일부가 선으로 잡힐 수 있으니, 숫자는 "세트 안 비교"용으로 쓴다.

## 2. 움직임 규칙 (앱에 이미 반영)

- 서버 포즈 webp는 **재생하지 않는다**(`CHARACTER_ART_AUTOPLAY = false`, 첫 장면에 멈춤). 그림 출처는 그대로 admin 등록 포즈다.
- 그 위에 `CharacterIdle`만 얹는다. 나의 방, 온보딩 캐릭터 고르기의 활성 카드, 닉네임 단계에서만 쓴다.
  - **숨쉬기**: 발밑을 축으로 세로 +2.2%, 1.8초 주기의 sine. 발이 바닥에서 뜨지 않는다.
  - **탭 반응**: 포즈가 넘어갈 때 한 번 눌렸다(세로 −7%) 스프링으로 돌아온다.
  - 시스템 "동작 줄이기"가 켜져 있으면 둘 다 하지 않는다.
- 집 좌석·친구 방처럼 여러 캐릭터가 함께 보이는 곳은 **정지**. 여럿이 같은 박자로 숨쉬면 기계처럼 보인다.
- 앞으로 눈 깜빡임과 꼬리를 넣으려면 그림을 **부위별 레이어**(몸 / 눈 뜬 것·감은 것 / 꼬리)로 받아야 한다(5절).

비교는 Dev 탭 → `CharacterIdle`(정지 vs 숨쉬기·탭 반응, 8종).

## 3. 다시 만들 때 지킬 규격

### 캔버스와 파일

- 원본은 **3배(996×855) PNG**로 그리고, 앱에는 332×285 webp로 내보낸다. 모든 종이 같은 캔버스다(곰 포함).
- **바닥선 고정**: 앉은 포즈와 누운 포즈 모두 발·배가 닿는 선을 캔버스 아래에서 같은 높이에 둔다. 방 렌더가 캐릭터를 바닥 기준으로 놓기 때문에, 바닥선이 다르면 포즈를 넘길 때 캐릭터가 위아래로 튄다.
- 그림 영역은 캔버스의 약 75~80%를 넘지 않는다(cat-1 실측 bbox 265×204).

### 선

- 굵기는 **332px 기준 2px**(원본 3배에서 6px). 전 종·전 포즈 동일. 강약을 줄 땐 안쪽 선(입·발가락)만 1.5px로 가늘게 한다.
- 색은 **세트 공통 따뜻한 갈색 하나**: cat-1 실측 `#655548`. 판다의 검은 털과 맞닿는 선만 `#433826`까지 허용한다.
- 선 끝은 둥글게(round cap). 선이 끊기거나 겹쳐 두꺼워지는 곳이 없게 한다.

### 비례와 얼굴 (cat-1 기준)

- **머리:몸 ≈ 1:1**(앉은 자세에서 머리 높이 ≈ 몸통 높이). 아기 동물 비례이되, 종에 따라 머리를 키우거나 줄이지 않는다.
- 눈: 머리 폭의 약 1/9 크기 검은 타원, 하이라이트 1개(왼쪽 위). 눈 사이 간격 ≈ 눈 지름의 3배.
- 입: ω 또는 짧은 ㅅ. 혀·윙크·반짝이 표시는 **쓰지 않는다**(지금 세트의 가장 큰 반복 패턴).
- 볼터치: `#eac6bd` 계열(cat-1), 투명도 40~60%, **눈 아래 바깥쪽**. 종에 따라 위치를 조금씩 달리해도 된다(완전히 같은 자리면 도장 느낌).

### 색

- 몸 색은 종마다 다르되 **채도를 낮게**(파스텔, cat-1의 회색·크림 정도). 그림자는 같은 색을 10% 어둡게 한 단 하나. 그라데이션과 광택은 쓰지 않는다.
- 발밑 그림자를 넣는다면 **모든 종·포즈에 같은 모양·같은 진하기**로. 하나라도 다르면 세트가 깨져 보인다.

### 포즈 — 4개에서 3개로

| 슬롯                | 용도                  | 지침                                                                                                                                                                                                          |
| ------------------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. 쉬기 (기본)      | 방에 처음 보이는 모습 | cat-1처럼 엎드리거나 누운 자세. 세트의 얼굴                                                                                                                                                                   |
| 2. 앉기             | 탭 1회                | 정면에서 살짝 비튼 3/4 각도. 완전 좌우대칭 금지                                                                                                                                                               |
| 3. 그 동물다운 동작 | 탭 2회                | 종마다 다르게 — 고양이: 앞발 핥기 / 강아지: 꼬리 흔들며 엉덩이 들기 / 호랑이: 기지개 / 판다: 대나무 잎 쥐기 / 곰: 배 깔고 엎드려 턱 괴기 / 양: 몸 동그랗게 말기 / 말: 앞발 하나 들기 / 수달: 누워서 조개 안기 |

손 흔들기(앞발 정면)와 네 발 서기는 뺀다. 둘 다 해부가 가장 많이 무너진 포즈다.

## 4. 만드는 순서

### 생성 도구를 쓸 때

1. **기준 이미지를 매번 함께 넣는다.** cat-1을 스타일 참조로 넣고, 같은 종의 1번(쉬기)이 정해지면 그 종의 2·3번은 **그 1번을 캐릭터 참조**로 넣어 같은 몸에서 포즈만 바꾼다. 포즈마다 처음부터 생성하면 비례가 매번 달라진다.
2. 프롬프트에 규격을 그대로 쓴다. 예:

   > Cute baby {animal} sticker, {pose}, flat pastel colors, single warm brown outline of uniform thickness, round line caps, no gradients, no sparkles, no tongue, no wink, transparent background, centered with feet on the bottom guide line, same proportions as the reference image (head about as tall as the body).

3. 후보를 여러 장 받아 **비례가 기준과 가장 가까운 것**을 고른다. 예쁜 것보다 같은 몸인 것이 우선이다.

### 사람이 다듬는 단계 (빼면 안 됨)

"AI 같음"은 대부분 여기서 빠진다.

1. **벡터로 따기**(Illustrator 이미지 추적이나 Figma에서 손으로): 선을 전부 같은 굵기의 스트로크로 다시 그린다.
2. 지운다: 반짝이, 윙크, 혀, 손가락처럼 갈라진 발, 털 질감 노이즈, 미세한 그라데이션.
3. 고친다: 앞발과 몸이 이어지는 곳, 다리 길이, 귀 좌우 크기(살짝 비대칭이 자연스럽다).
4. 볼터치·눈 하이라이트를 손으로 다시 찍는다(위치를 아주 조금씩 다르게).
5. 3배 원본으로 내보내고 332×285 webp로 줄인다.

### 외주로 갈 때

이 문서를 브리프로 그대로 준다. 요청 범위: 8종 × (기준 시트 1장 + 포즈 3개), 원본 벡터, 3배 PNG. 눈 깜빡임과 꼬리를 쓸 거면 5절의 레이어도 함께 요청한다.

## 5. (다음 단계) 부위별 레이어

눈 깜빡임·꼬리 움직임을 코드로 하려면 포즈마다 다음을 같은 캔버스·같은 원점의 투명 PNG로 받는다.

- `body` (눈·꼬리 제외)
- `eyes-open`, `eyes-closed`
- `tail` (꼬리 뿌리 위치를 회전축으로 표시)

이게 있으면 `CharacterIdle`에 3~5초 간격의 무작위 깜빡임과 꼬리 흔들기를 얹을 수 있다(OTA 가능, 새 라이브러리 없음).

## 6. 합격 기준

새 세트를 넣기 전에 확인한다.

- [ ] `python3 scripts/character-art-audit.py <폴더>`가 **기준 이탈 없음**: 캔버스 332×285, 선 2px, 세트 외곽선 밝기 차이 40 이내.
- [ ] 같은 종 포즈 3장을 겹쳐 봤을 때 머리 크기·눈 간격이 같다.
- [ ] 반짝이·윙크·혀가 없다.
- [ ] Dev 탭 `CharacterIdle`에서 포즈를 넘겨도 캐릭터가 위아래로 튀지 않는다(바닥선 일치).
- [ ] 8종을 한 장에 모아 봤을 때 "한 사람이 그린 세트"로 보인다. 팀원 한 명 이상에게 AI 같은지 물어본다.
- [ ] 서버(admin) 포즈 등록도 같은 파일로 바꾼다. 앱은 서버 포즈가 있으면 그것을 쓴다.

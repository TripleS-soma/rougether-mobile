# 거래소와 소셜 화면 정리

2026-11-11 사용자 화면 피드백 (#1744)을 반영합니다.

- 거래소는 2열 그림 카드와 한 줄 관리 버튼을 사용합니다. 첫 화면의 구매·보관 안내를 제거합니다.
- 알림과 새 소식 제목은 줄바꿈하고 시각 영역은 줄어들지 않도록 분리합니다. 피드 본문은 18px에서 16px, 알림 제목은 16px에서 14px로 줄이며 선택 폰트와 OS 글자 배율을 유지합니다.
- 자유/인증 작성은 본문, 사진 추가, 완료 루틴 선택 순서입니다. 본문을 가리는 채움 배경과 중복 안내를 제거합니다. 인스타그램의 사진과 캡션 중심 구성을 참고하되, 글만 쓰는 앱 흐름을 유지합니다.
- 인증은 유효한 완료 루틴 한 건만으로 제출할 수 있습니다. 사진은 0~10장, 본문도 선택입니다. 자유글은 사진이 없으면 본문이 필요합니다. 업로드 중/실패한 사진은 계속 제출을 막습니다.
- AI 가구에는 실제 생성 결과 중 눈으로 확인한 통기타, 찻잔, 곰 장식을 표시합니다. 공개 출력 asset key만 사용하고 원본 사진과 계정 정보는 포함하지 않습니다. 비용은 “생성권 or 100코인 사용”으로 표시합니다.
- 초대코드 설명은 “참여는 방장 승인 후 확정”입니다.

## 배포 순서

서버 PR #525와 spec PR #154의 사진 선택 정책이 먼저 반영되어야 합니다. 앱만 먼저 배포하면 사진 없는 인증 요청이 기존 서버에서 거절됩니다. 캐릭터 크기 배포와는 분리한 후속 PR입니다.

## 확인

390px 거래소 2열, 320px 긴 알림 시각 표시, 글만 쓰는 자유글, 빈 자유글 차단, 사진 없는 인증 활성화를 Dev 갤러리에서 직접 확인했습니다. 갤러리는 고정된 완료 날짜의 테스트 데이터이며 실제 회원에게 게시하지 않습니다. API 훅 테스트와 서버 HTTP 통합 테스트로 빈 imageIds 전송과 저장을 별도 검증합니다.

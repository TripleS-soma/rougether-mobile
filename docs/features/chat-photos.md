# 집 채팅 사진

입력창 사진 버튼 → 시스템 사진 선택기 → 미리보기 → 보내기 순서다. JPEG/PNG 한 장(10MB 이하)을 보낼 수 있다. 실패한 사진은 같은 메시지 ID와 업로드 ID로 재시도한다. 목록 재조회로 실패한 말풍선을 지우지 않는다.

서버 #532와 spec #155 계약을 사용한다. 사진은 공개 CDN이 아닌 인증 API로 읽고 디스크에 캐시하지 않는다. 배경 진입과 로그아웃 시 표시를 비우며 복귀 시 접근 권한을 다시 확인한다. 계정이나 집이 바뀐 뒤 이전 업로드를 전송하지 않는다. 다른 구성원의 메시지는 신고할 수 있다.

기존 Expo SDK 55 사진 선택기를 사용하며 네이티브 설정과 권한 요청을 추가하지 않는다. 개인정보처리방침 2.4(landing #77)에 선택한 사진의 수집, 현재 집 구성원 공개, 삭제와 AI 미전송을 반영했다. 사진 접근 권한과 재전송 경로는 API 세션·훅·화면 테스트로 검증한다.

발행 전 서버의 인증 업로드/조회/취소를 확인한다. production과 이전 iOS/Android 런타임 모두에 발행하며 네이티브 지문은 기존 설치본과 대조한다. 앱 업데이트 게시 성공과 개별 기기의 업데이트 수신은 별도로 판단한다.

## 크게 보기와 피드에 올리기 (2026-11-11)

말풍선 사진을 누르면 검정 바탕의 전체 화면 보기가 열린다. 왼쪽 위에 뒤로가기와 보낸 사람·보낸 시각이 있다. 종전에는 테마 바탕 위에 사진이 작게 떠 있고 "닫기" 글자만 있었다.

내가 보낸 사진에는 가운데 아래에 [피드에 올리기]가 붙는다. 누르면 그 사진이 붙은 피드 작성 화면(자유게시판)이 열리고, 본문을 쓴 뒤 직접 [올리기]를 눌러야 게시된다. 사진은 메모리에 있던 것을 피드 업로드 API로 다시 올린다 — 채팅 사진을 디스크에 쓰지 않는 원칙은 그대로다. 채팅 사진은 그 집 구성원에게만 보이는 사진이라, 남이 보낸 사진에는 이 버튼을 붙이지 않는다. 피드가 꺼진 빌드에도 없다.

작성 화면에서 뒤로 가면 채팅이 아니라 피드 탭으로 간다(작성 화면의 기존 뒤로 경로).

기기 앨범에 저장하는 기능은 넣지 않았다. 원본 저장에는 파일 쓰기 모듈이 직접 의존성으로 필요하고, 추가하면 네이티브 지문이 바뀐다.

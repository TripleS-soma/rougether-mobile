# 1.4.2 / iOS 빌드 113 통합 (#1114)

## 승인 범위

- 사용자 요청: 세로형 집과 다크 배경을 병합하고 새 빌드 113으로 TestFlight 배포한다. App Store 심사 제출은 별도다.
- #1078을 기본 OFF 상태로 dev에 병합했고 중간 `eas-deploy` 런 34018759570을 취소했다. 최종 통합 후 main의 `store-build`를 iOS로 한 번만 실행한다.
- `app.json`의 앱 버전은 1.4.2로 올린다. 빌드 번호는 EAS remote가 관리하며 `expected_ios_build=113`으로 현재 번호 + 1을 검사한다. 다르면 중단하고 번호를 강제 되돌리지 않는다.

## 포함되는 화면 변화

- 기존 구름·산호·버섯 집의 세로형 프레임을 기본 활성화한다. 정원 2/4/6에 맞춰 1/2/3층이 된다. 밤의 천문대는 호환 프레임이 없어 기존형을 유지한다.
- 기존 집 네 테마 모두 별도 다크 배경을 사용한다. 새 세로형 프레임도 원래 커버 키로 배경을 선택한다.
- 집 정원 선택지는 2–6명, 기본 4명. 현재 인원 미만 축소를 차단하며 기존 7–10명 집은 보존한다.
- 개인 방은 교체된 벽지 30종·바닥 12종의 카탈로그를 그대로 사용한다. 렌더 계약을 벽 0.6667 / 바닥 0.3333, 각각 bottom / top 크롭 기준으로 맞춘다. 가구/캐릭터 좌표와 소유 관계는 변경하지 않는다.
- 팀원의 마이페이지, 테마 적용 버튼, 하단바 누른 채 슬라이드와 Android 측정 수정 #1109를 유지한다.
- 새 일곱 집 테마의 공개 카탈로그·뽑기 판매는 이번 범위에 없다.

## 통합 보강

- 이미지 실패 상태는 집 전환 시 재시도한다. art와 좌표는 함께 기존형으로 폴백한다.
- 썸네일은 호출자가 지정한 crop/contain을 존중하고 커버 선택 그리드는 같은 높이를 유지한다.
- 탐색 미리보기는 단일 세로 스크롤을 사용한다. 예외적인 3칸 이상 행도 멤버를 숨기지 않는다.
- 1px 이하 측정 흔들림은 확대 카메라를 초기화하지 않는다. 모드 전환 때 커버를 중복 프리패치하지 않는다.

## 배포 게이트

1. typecheck/lint/format/전체 Jest 및 PR CI 통과.
2. `release-smoke` 라벨의 Xcode 26.2 Release 시뮬레이터 빌드·실행. 산출물 `first-screen.png`를 사람이 확인한다. 프로세스 생존만으로 첫 화면 성공을 주장하지 않는다.
3. 검증 후 기능 PR squash → dev 자동 배포 취소 → dev→main merge commit 승격 → iOS `store-build` 실행.
4. EAS 실제 빌드 번호·런타임·TestFlight 제출 결과를 확인한다. production OTA나 App Store 심사 제출은 자동 실행하지 않는다.

로컬에는 Xcode 27 / iOS 27만 설치돼 기존 UIScene 설정으로 시작이 차단됐다. 앱 설정을 임의로 우회하지 않고 별도 Xcode 26.2 검증을 사용한다. 개인 방 에셋 44개(카탈로그 42개+기본 후보 2개), 세로형 프레임 30개는 2026-09-06 CDN 응답과 원본 SHA-256을 전수 대조했다.

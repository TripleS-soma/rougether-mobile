# 마케팅용 집 에셋

집 6종의 가구 없는 원본 PNG다. 각 파일은 1024×1536, 세로 2:3 비율이며 배경이 포함되어 있다. 투명 배경이나 집만 잘라낸 파일이 아니다. 앱용 768×1152 WebP는 assets/houses/shared-v1에 있다. manifest.json에서 파일과 해시를 확인할 수 있다.

Storybook의 **에셋 / 공동집**에서 6종을 비교하고 각 PNG와 WebP를 내려받을 수 있다. 인원과 가구를 바꾸는 조절판은 실제 HouseDioramaPreview 컴포넌트를 사용한다. 거기에 표시되는 멤버와 배치는 샘플이고 가구 이미지는 실제 CDN 에셋이다.

- PNG: 마케팅 이미지와 영상의 배경으로 사용할 원본
- WebP: 실제 앱에서 사용하는 경량 이미지
- 가구와 캐릭터가 포함된 화면: Storybook의 조절판, 또는 docs/design/house-diorama 검증 캡처 참고

이 PNG에는 가구나 캐릭터가 들어 있지 않다. 같은 artwork를 사용하되 가구와 캐릭터는 앱에서 따로 합성한다. 신규 디자인은 아직 출시 전이며, 운영 앱에 적용됐다는 문구는 배포 확인 후 사용한다.

이 폴더는 Storybook 정적 에셋으로만 제공한다. 앱에서 import하지 않으므로 원본 PNG 6개를 모바일 번들에 추가하지 않는다. 생성형 이미지 원본이며 별도의 외부 작가나 스톡 출처를 표시하지 않는다.

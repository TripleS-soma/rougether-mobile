# 뽑기 시네마틱 연출 기준

승인된 수채화 방·초록 리본 선물 상자를 하나의 공통 무대로 사용한다. 벽지·바닥·가구의 종류와 테마는 영상 파일 수에 영향을 주지 않는다.

소스는 `1080×2340`, 모바일 출력은 `720×1560`이다. 실제 휴대폰의 약 `19.5:9` 비율에서 문구와 가구가 한 화면에 들어오도록 설계했다.

일반은 2.4초, 희귀는 2.7초, 전설은 2.9초다. 가장 높은 등급은 더 긴 기대, 더 깊은 카메라 당김, 짧은 정적, 공개 시 빛 확산으로 구별한다. 원본 금빛 포털을 보존하고 별도 CSS 동심원·쇼크링·UI 테두리를 없앴다. 작은 빛의 움직임은 비대칭으로 처리한다.

가구 원본 알파를 앱에서 별도 합성한다. 최대 팝 영역은 소스 기준 `470×460`, 중심은 `(540,780)`이다. 사각 카드나 불투명 배경을 넣지 않는다. 상자 덮개와 안전한 간격을 확보하기 위해 포털 중심보다 30px 위에 놓는다.

공개 시점은 일반 1.1초, 희귀 1.3초, 전설 1.55초다. 영상의 짧은 스팅·우시와 앱의 진동·가구 등장을 이 시점에 맞춘다. 최종 카메라 좌표는 원점이고, 마지막 프레임에서 추출한 등급별 포스터를 결과 화면에서 유지한다.

영상에는 가구, 문구, 버튼, 로고를 굽지 않는다. 상자는 한 장의 승인된 일러스트이므로 뚜껑을 독립적으로 여는 동작은 포함하지 않는다.
